## 2017 curriculum

**[42_Paris_2017](../../42_Paris_2017/)** contains two main strands:

- **[Piscine_C_2017](../../42_Paris_2017/Piscine_C_2017/):** daily C/Unix exercises, subjects and practice code.
- **[Cursus_2017](../../42_Paris_2017/Cursus_2017/):** folders present in the archive include `42_commandements`, `docker-1`, `fdf`, `fillit`, `fract_ol`, `ft_printf`, `get_next_line`, `init`, `libft` and `piscine_reloaded`.

These are snapshots of historical learning material, not a promise that old projects compile under modern toolchains without adjustments.

## 2023 curriculum

**[42_Paris_2023](../../42_Paris_2023/)** includes:

- **[Piscine_C_2023](../../42_Paris_2023/Piscine_C_2023/):** `Shell_00`, `Shell_01`, multiple `C_XX` modules and `Rush` exercises.
- **[Cursus_2023](../../42_Paris_2023/Cursus_2023/):** hosts the nested [`Projects/`](../../42_Paris_2023/Cursus_2023/Projects/) repository.
- **[Association_2023](../../42_Paris_2023/Association_2023/):** `BDE` and `Blackout` materials.

### Beyond the Common Core

[`Post_CC/`](../../42_Paris_2023/Cursus_2023/Projects/Post_CC/) contains folders named `Realeased` and `Unrealeased` in the supplied archive, including a `Darkly` project and other work under `Unrealeased`.
