## Overview

This document helps navigate the main sections of `42_Paris`.

## Main folders

### `42_Paris_2017`
Historical archive of the first period at 42: Piscine material, early C projects and initial cursus work.

### `42_Paris_2023`
Modern journey through the renewed curriculum:
- Piscine
- Common Core
- Post-Common Core work
- tools and association material

### `Others`
Personal zone for tools, experiments, shell helpers, notes and Git customization.

### `.assets`
Centralized visuals and documentation used by the root README files.
