# Assets guide

This folder centralizes all resources used by the root README files.

## Structure

```text
.assets/
├── docs/     # supporting documentation
├── images/   # banners and static visuals used by the README files
├── text/     # text exports and auxiliary data
└── tree/     # markdown tree snapshots
```

## Philosophy

- keep README dependencies local
- avoid hotlinked images
- keep section banners visually consistent
- separate design assets from source-code repositories
